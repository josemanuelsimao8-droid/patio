Espaços

Um lugar, diferentes formas de viver Luanda.

Entre sabores, encontros e momentos de lazer, cada espaço do Pátio foi pensado para proporcionar uma experiência diferente — mas sempre com a mesma atmosfera acolhedora.

A experiência

Feito para ficar

O Pátio foi pensado para ser mais do que um lugar para comer. É um espaço de encontro, de descanso e de descoberta, onde diferentes ambientes se cruzam para criar uma experiência completa.

Durante o dia, é lugar para almoços tranquilos, encontros de trabalho e momentos de lazer. À noite, transforma-se num cenário para jantares, conversas e encontros que se prolongam.
